# Hotel Terabithia

Sistema de gerenciamento hoteleiro desenvolvido em HTML e JavaScript.

## Funcionalidades

### Hotel.html
- Login de funcionário com limite de tentativas.
- Menu principal de operações.
- Reservas de quartos.
- Cadastro e gerenciamento de hóspedes.
- Organização de eventos.
- Orçamentos de ar-condicionado.
- Comparação de abastecimento.
- Relatórios financeiros e operacionais.

### CadastroDeHospedes.html
- Cadastro de hóspedes.
- Pesquisa por nome.
- Pesquisa por prefixo.
- Listagem em ordem alfabética.
- Atualização de cadastros.
- Remoção de hóspedes.

## Tecnologias utilizadas

- HTML5
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Abra `Hotel.html` no navegador.
4. Para acessar o módulo independente de hóspedes, abra `CadastroDeHospedes.html`.

**Senha de acesso:** `2678`

## Observação

Os dados são armazenados em memória durante a execução. Ao atualizar ou fechar a página, os registros podem ser perdidos.

Praticar lógica de programação, funções, estruturas condicionais, repetições, arrays e organização de código em JavaScript.
