# Hora de Codar: Um Novo Dia Para Codar

## Objetivo

Praticar o armazenamento, a consulta, a busca e a remoção de informações por meio de listas, utilizando estruturas de repetição e métodos de arrays.

## Exercícios desenvolvidos

### 1. Estudantes
Programa que permite cadastrar nomes de estudantes em um array até que o usuário digite "PARE". Ao finalizar, exibe a quantidade de estudantes cadastrados e seus nomes.

### 2. Planetas
Lista os planetas do sistema solar e verifica se o planeta informado pelo usuário está presente no array.

### 3. Compras
Cria uma lista de frutas e permite remover itens conforme a escolha do usuário. Ao final, exibe as frutas restantes ou informa quando a lista está vazia.

## Conceitos praticados

- Arrays.
- Variáveis e tipos de dados.
- Estruturas de repetição (`while` e `for`).
- Condicionais (`if/else`).
- Métodos `push()`, `includes()`, `indexOf()` e `splice()`.
- Propriedade `length`.
- Entrada e saída de dados com `prompt()` e `alert()`.

## Tecnologias

- HTML
- JavaScript

## Como executar

1. Baixe ou clone o repositório.
2. Acesse a pasta `Um-novo-dia-para-codar`.
3. Abra qualquer um dos três arquivos dos exercícios em um navegador.
4. Interaja com o programa pelas caixas de diálogo.
