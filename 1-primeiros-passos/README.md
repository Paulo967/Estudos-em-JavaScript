# 💻 Hora de Codar — Primeiros Passos

> Minha jornada na lógica de programação começa aqui: transformando problemas em soluções com JavaScript.

## Sobre o projeto

Este repositório reúne os exercícios desenvolvidos durante o módulo **Primeiros Passos**, do Hora de Codar.

A proposta é desenvolver o raciocínio lógico, compreender os fundamentos da programação e aprender a construir soluções utilizando JavaScript.

Cada exercício representa uma oportunidade de praticar conceitos, testar possibilidades, identificar erros e desenvolver autonomia na resolução de problemas.

## Objetivos de aprendizagem

- Desenvolver raciocínio lógico.
- Trabalhar com variáveis e tipos de dados.
- Receber e apresentar informações ao usuário.
- Aplicar operadores matemáticos e relacionais.
- Construir estruturas condicionais.
- Utilizar laços de repetição.
- Resolver problemas de forma estruturada.

## Tecnologias utilizadas

- JavaScript
- Visual Studio Code
- Git
- GitHub

# Exercícios desenvolvidos

## 01. Primeiros Passos

**Objetivo:** praticar os fundamentos da linguagem e aprender a interagir com o usuário.

| Questão | Desafio | Conceitos praticados |
|---|---|---|
| 1.1 | Criar uma variável com o nome de um carro e exibir seu valor. | Variáveis e `alert()` |
| 1.2 | Solicitar o nome do usuário e apresentar uma saudação. | `prompt()` e concatenação |
| 1.3 | Solicitar nome e idade e apresentar uma mensagem personalizada. | Variáveis e concatenação |

**Desafios extras:**
- Exibir o nome em letras maiúsculas.
- Contar os caracteres do nome.
- Criar uma saudação motivacional.

## 02. Condicionais

**Objetivo:** desenvolver programas capazes de tomar decisões com base em condições.

| Questão | Desafio | Conceitos praticados |
|---|---|---|
| 2.1 | Ler dois números e mostrar o maior. | `if/else` e operadores relacionais |
| 2.2 | Identificar se um número é positivo, negativo ou zero. | Condicionais |
| 2.3 | Identificar o maior entre três valores diferentes. | Condicionais compostas |
| 2.4 | Calcular a soma dos dois maiores entre três valores. | Comparações e operações matemáticas |
| 2.5 | Ler seis valores e calcular a média aritmética. | Variáveis e operações matemáticas |
| 2.6 | Informar o primeiro, o último e o maior entre quatro valores. | Comparações |
| 2.7 | Somar valores menores que 72 entre seis números informados. | Condicionais e acumuladores |
| 2.8 | Validar quatro notas e verificar se a média é maior que 5. | Validação e condicionais |
| 2.9 | Verificar se uma pessoa pode votar com base no ano de nascimento. | Operadores relacionais e condicionais |

**Desafios extras:**
- Identificar também o menor número.
- Tratar entradas inválidas.
- Calcular e apresentar a idade do usuário.

## 03. Laços de Repetição

**Objetivo:** desenvolver soluções que executam instruções repetidamente, utilizando condições de continuidade e encerramento.

| Questão | Desafio | Conceitos praticados |
|---|---|---|
| 3.1 | Criar uma contagem regressiva de 30 até 0. | `for` e contadores |
| 3.2 | Solicitar novamente um divisor enquanto ele for menor ou igual a zero. | `while` e validação |
| 3.3 | Calcular a média dos inteiros de 15 a 100. | Laços e acumuladores |
| 3.4 | Calcular a média dos números inteiros entre dois valores. | Laços e operações matemáticas |
| 3.5 | Calcular médias de alunos e contar os aprovados. | Repetição, condicionais e contadores |
| 3.6 | Ler seis notas válidas e calcular a média. | Validação e repetição |
| 3.7 | Imprimir os números inteiros de 1 até N. | Laços e variáveis |
| 3.8 | Imprimir os dez primeiros números inteiros maiores que 100. | Laços e contadores |
| 3.9 | Contar quantos valores estão dentro e fora do intervalo de 24 a 42. | Condicionais e contadores |

**Desafios extras:**
- Personalizar o início da contagem regressiva.
- Exibir soma e quantidade de valores utilizados nas médias.
- Apresentar separadamente os números dentro e fora do intervalo.

## Desafio Final — Menu Interativo

Desenvolver um programa com menu de navegação entre as três etapas do módulo.

- `1` — Primeiros Passos
- `2` — Condicionais
- `3` — Laços de Repetição
- `0` — Sair

**Conceitos praticados:** organização de código, estruturas condicionais, laços de repetição e reutilização de lógica.
