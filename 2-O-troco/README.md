# Hora de Codar: O Troco

Projeto desenvolvido durante os estudos de lógica de programação no Instituto PROA. O desafio consiste em aprimorar um sistema bancário existente, implementando novas funcionalidades e regras de validação com JavaScript.

## Objetivo

Praticar lógica de programação por meio da evolução de um código existente, trabalhando com operações bancárias, estruturas condicionais, funções e validação de dados.

## Versões do projeto

### ContaBancaria.html — Versão inicial
- Consulta de saldo.
- Depósito.
- Saque.
- Menu de operações.
- Saudação personalizada.

### ContaBancaria-SPROA.html — Versão aprimorada
- Menu com `switch/case`.
- Consulta de saldo protegida por senha.
- Extrato com movimentações fictícias.
- Saque com validação de saldo e valor.
- Depósito com validação de valor.
- Transferência entre contas.
- Validação de senha para operações protegidas.
- Confirmação de saída do sistema.

## Conceitos praticados

- Variáveis e tipos de dados.
- Funções.
- Condicionais (`if/else`).
- Estrutura de seleção (`switch/case`).
- Operadores aritméticos e lógicos.
- Conversão e validação de dados.
- Recursividade.
- Entrada e saída de informações com `prompt`, `alert` e `confirm`.

## Tecnologias

- HTML
- JavaScript

## Como executar

1. Baixe ou clone este repositório.
2. Acesse a pasta `2-O-troco`.
3. Abra o arquivo `ContaBancaria-SPROA.html` em um navegador.
4. Interaja com o sistema pelos menus e caixas de diálogo.

## Observação

Este projeto possui finalidade educacional. As movimentações do extrato são fictícias e o sistema não utiliza banco de dados ou autenticação real.
